## Project Overview
Blackjack is an iOS application developed to offer players a robust and engaging platform for enjoying the classic game of Blackjack. The app provides a comprehensive experience by integrating dynamic features such as multiple difficulty levels, theme customization, and sound effects to enhance gameplay. Designed with SwiftUI, the application aims to deliver an intuitive and interactive user experience, suitable for both novice and experienced players.

## Features
- **Welcome Screen**: Displays the app logo and provides a button to navigate to different views, offering a user-friendly introduction to the app.
- **Gameplay**: The main screen where players can enjoy playing Blackjack with two different modes: Standard and Timer. The Standard mode follows the traditional rules, while the Timer mode adds a time-based challenge to increase difficulty.
- **Leaderboard**: Displays the top players and their scores, allowing users to track their progress and compare their performance against others.
- **GuideView**: An interactive guide that provides players with information on how to play the game, including game objectives, rules, card values, and gameplay. This view helps players understand and master the game.
- **Setting**: A comprehensive settings view where users can customize their game experience, including adjusting difficulty levels, switching themes, managing sound settings, and selecting languages for localization.
## Getting Started

### Prerequisites
- Xcode 14 or later
- Swift 5.7 or later
- iOS 17.0 or later

### Installation
1. Clone the repository:
    ```bash
   git clone https://github.com/RMIT-Vietnam-Teaching/cosc2659-cosc2813-ios-assignment-2-2024b-spjk1910.git
    ```
2. Open the project in Xcode:
    ```bash
   cd cosc2659-cosc2813-ios-assignment-2-2024b-spjk1910
   open ASM2_IOS.xcodeproj
    ```
3. Build and run the project on your preferred iOS device or simulator.
